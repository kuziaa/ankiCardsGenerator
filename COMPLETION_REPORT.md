## Как начать использовать

### Шаг 1: Установка
```bash
pip install -r requirements.txt
```

### Шаг 2: Проверка
```bash
python check_setup.py
```

### Шаг 3: Конфигурация
```bash
cp config.properties.sample config.properties
# Отредактируйте если нужны изображения
```

### Шаг 4: Запуск
```bash
cd src
python anki_generator.py
```
