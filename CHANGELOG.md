- Язык: Python 3.7+

- Логирование: встроенный модуль logging
- Конфигурация: properties файлы
- Формат выхода: APKG (Anki deck package)

### 🎯 Миграция с v1.0 на v2.0

Для пользователей v1.0:

1. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Конфигурация** (опционально):
   ```bash
   cp config.properties.sample config.properties
   ```

3. **Запуск** (без изменений):
   ```bash
   cd src
   python anki_generator.py
   ```

✅ Все старые конфигурации и CSV файлы работают без изменений!

### 📝 Примечания для разработчиков

**Для расширения функционала:**
1. Смотрите примеры в `examples.py`
2. Изучите документацию в `README.md`
3. Смотрите раздел "Расширение функционала" в `README.md`

**Для добавления нового типа карточки:**
1. Создайте модель в `src/models/your_model.py`
2. Добавьте создание в `card_generator.py`
3. Используйте в `anki_generator.py`

## v1.0.0 (Оригинальная версия)

### Возможности
- Генерирование аудио для слов (gTTS)
- Скачивание изображений (Google Custom Search)
- Создание 5 типов карточек (typing, choice, scramble)
- Экспорт в APKG формат
- Перемешивание карточек

### Ограничения (исправлены в v2.0)
- ❌ Монолитный скрипт без модульности
- ❌ Простое логирование через print()
- ❌ Ошибка в одном слове = крах всего процесса
- ❌ Hardcoded ID деки (999004)
- ❌ Нет файлов логов
- ❌ Нет документации
- ❌ Нет обработки edge cases
